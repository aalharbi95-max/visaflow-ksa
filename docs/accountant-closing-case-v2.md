# Accountant month-close case, version 2

The candidate constructs four net correcting entries from a full chart of accounts, explains each entry, calculates the combined change in profit and assets, and discusses a separate incomplete-documentation scenario. The fictional October case excludes tax and allows approximately 35 minutes.

Two numerical variants are assigned deterministically by candidate UUID and enforced by the save RPC. This is one attempt per assigned version, not a retake mechanism. Structured answers total 100 points; written explanations require human review and do not automatically earn points. The result is evidence for this case, not a professional qualification.

Version 1 definitions, answer keys, attempts and scores are preserved. Prior attempts appear as read-only archived versions. Their existing review rights remain available. Answer keys stay in protected database records and server-only seed scripts, never in the production frontend.

Validation: actual migrations and authenticated RPCs in PGlite cover both variants, partial scoring, consent and explanation requirements, revision conflicts, immutable submissions, assigned-case enforcement, archive preservation and access controls. Candidate UI submission was also checked in a local fixture. Deployment uses migration 20260911000500 followed by the isolated production frontend snapshot.
